#  Documentary - The SolarWinds Hack
- Attackers secretly hacked SolarWinds' Orion software. They hided malicious code into a software update, so when
customer downlaods the update - he downloads attackers code also. The victim was SolarWinds company. SolarWinds used
the Orion software, which was used by almost thousands of organizations including also U.S. government agencies.
The attackers were later attributed by the U.S. government to russian SVR intelligence service, which associated
with APT29 (Cozy Bear). This was a supply-chain attack. It's when attackers attacking trusted third party company which
supplies compromised company with software. It's dangerous because all of the customers that recieves software from
one party may be infected with virus and the problem is that the customers trust the third party company.
- The Integrity part of CIA triad was attacked. The attackers modified software for SolarWinds. In the result customers
recieved software that appeared genuine but had been altered. And it means that integrity has become a vulnerability.
Then the security employee notices that some unfamiliar device has been added to an employee's account for 2-factor
authentification. That made FireEye realize that someone has gotten inside its systems. One important defence
would be stronger security monitoring of software updates and the software development process. SolarWinds could have
used stricter controls and monitoring to detect unauthorized changes to its software before an update was released. 
Perhaps it wouldn’t have prevented the attack, but it would have been detected even earlier.
- The SolarWinds incident showed the cybersecurity world that even trusted software and trusted suppliers cannot
automatically be considered safe.
